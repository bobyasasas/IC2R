# 回收机

回收机保留每件物品 45 刻、1 EU/t、八分之一废料概率，基础实际储能 90 EU，支持现有四格加工／电压／储能与物品自动化升级。本体生存合成已转换。

黑名单物品仍消耗 45 EU 并被销毁，完全不产出废料；因此输出槽被占满时也可以销毁这些物品。普通物品必须先确保有废料位置，才推进加工，即使该次随机结果最终为空。

概率仅在实际完成时调用一次原生 `nextInt(8)`。模拟、输出阻塞和保存不会提前抽取随机结果；升级额外操作同样先检查潜在产物空间再消耗输入。共同加工流程为概率结果增加小型完成钩子，不复制整个加工状态机。

黑白名单使用 `ic2:recycler_blacklist` 和 `ic2:recycler_whitelist` 物品标签。非空白名单覆盖黑名单；默认白名单为空。旧默认黑名单中的 `snow_layer` 归一到现代 `minecraft:snow`，其余为玻璃板、木棍和雪球。管理员可以通过数据包扩展或替换标签。

输入物品类型及组件变化会清空当前工作；完整输入身份单独保存，避免重载把最后一刻的进度误清零。

验证：46 项核心 JUnit；IC2／GT 各 68 项 GameTest（67 项 IC2 + 1 项原版）。回归覆盖四个默认黑名单物品、固定种子 64 次加工与原生随机序列逐项计数、最后一刻重载和堵塞不抽签、组件变化重置进度。循环声音使用旧回收机资源。

P09 继续推进感应炉，以及离心机合成、核材料和铁栅栏相关依赖。
