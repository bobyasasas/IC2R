# 热爆炸基础

蒸汽发生器依赖恢复版 `Ic2Explosion.Type.Heat`。热爆炸有额外六倍固体热阻，不能直接用同参数的普通 TNT 爆炸替代。本切片先建立该依赖；蒸汽发生器本体继续迁移，核爆、反应堆熔毁、辐射和炸药尚未实现。

核心 `HeatBlast` 是无世界修改的有界射线计算。支持锅炉使用的 1–10 强度；空气每格吸收 0.5、水 1.5，固体吸收 `0.5 + (resistance + 4) × 1.8`。保留恢复版的角度采样、实体采样间距和大于 8 强度时不留方块掉落的规则。这个强度范围内不会进入旧的二次散射分支，因此不引入递归射线和无界工作量。同一方块每次爆炸只读一次热阻；计算结果为不可变集合。

平台 `HeatExplosion` 继承原生 `ServerExplosion` 并连接 NeoForge 的 Start／Detonate／击退事件。Start 取消时，包括锅炉自身移除在内的修改全部停止；Detonate 可以过滤受影响方块和实体。破坏调用原生方块爆炸钩子，尊重掉落游戏规则并按给定掉落率处理。伤害调用服务端伤害入口，击退归一化在爆心为零时不会产生 NaN，并考虑原生击退抗性；通过原生爆炸包同步粒子、声音和玩家击退。

明确调整：旧实现会让未加入白名单的超高抗爆方块透射爆炸，新实现让这些方块阻断热射线；未加载区块、世界边界也阻断射线，不强制加载地形。实体伤害在射线汇总后提交一次，避免旧实现根据估计生命值中途施伤的重复路径。

独立 35³ 测试场覆盖：完整取消、Detonate 的方块／实体过滤、热阻与基岩、真实实体伤害、爆心有限击退，以及对未加载远处坐标触发爆炸后区块仍未加载。核心测试覆盖热阻、有限传播和单次地形采样。
